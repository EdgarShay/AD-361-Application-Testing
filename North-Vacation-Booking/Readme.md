# North Vacation Booking - Black-Box Testing- P2
Written by: Edgar

## Project Overview
For this project, I will practice black-box testing using the requirements for an application called North Vacation Booking.
The application allows homeowners to list their homes as vacation rentals and allows guests to make reservations.
I will use the requirements to identify conditions, actions, reservation states, and possible transitions without examining the application's source code.

## Testing Techniques
This project focuses on two black-box testing techniques:

- Decision Table Testing
- State Transition Testing

## Project Files
| File | Description |
|---|---|
| st1-conditions-actions.md | Identifies five conditions and five actions |
| st2-decision-table.md | Creates the decision table with six rules |
| st3-decision-table-test-cases.md | Creates test cases for each decision rule |
| st4-states-events.md | Identifies reservation states and events |
| st5-state-transition-table.md | Documents valid and invalid transitions |
| st6-state-transition-test-cases.md | Creates state transition test cases |

## Conclusion
This project helps me understand how to design black-box tests using application requirements.
I will practice identifying different conditions, actions, states, and transitions to make sure the application behaves as expected.
