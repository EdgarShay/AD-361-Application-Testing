# Step 1: Exploratory Testing

## Testing Charter

For this testing session, I will explore the counter application to understand how the buttons work
and how the displayed count changes. I will test different combinations of actions, including incrementing,
decrementing, and resetting the counter. I will also check how the application behaves when I perform
several actions in a row.

## Exploratory Testing Results

| Action | Expected Result | Actual Result | Pass or Fail |
|---|---|---|---|
| Click Increment once | Count changes from 0 to 1 | Count changed to 1 | Pass |
| Click Decrement once | Count changes from 0 to -1 | Count changed to -1 | Pass |
| Click Reset | Count returns to 0 | Count returned to 0 | Pass |
| Click Increment three times | Count changes to 3 | Count changed to 3 | Pass |
| Increment twice and decrement once | Count changes to 1 | Count changed to 1 | Pass |

## Conclusion

The counter application worked as expected during my exploratory testing.
I was able to increase, decrease, and reset the count. I also tried different combinations of actions
to check if the count updated correctly.
