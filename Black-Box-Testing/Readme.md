# Black-Box Testing Assignment
- NVIDIA
Written by: Edgar

## Project Overview

For this project, I selected the NVIDIA website to practice black-box testing.

Black-box testing allows me to test a website from the user's perspective without looking at its source code.
I focus on the information I enter, the actions I perform, and the results displayed by the website.

## Website

- **Name:** NVIDIA
- **URL:** https://www.nvidia.com/en-us/

## Features Tested

1. Product search: Testing how the website responds to different search inputs.
2. Product navigation: Testing how users navigate through product categories and product information.

## Testing Techniques

This project uses three black-box testing techniques:

- **Equivalence Partitioning:** Dividing search inputs into groups with similar expected results.
- **Decision Table Testing:** Testing different conditions and the actions the website should perform.
- **State Transition Testing:** Testing how the website changes from one state to another when users perform actions.
