# North Vacation Booking - Testing
Written by: Edgar

## Description
- This project practices black-box testing and equivalence partitioning. The goal is to design test cases based on application requirements without looking at the source code.

## Topics
- Black-box testing
- Equivalence partitioning
- Valid and invalid partitions
- Test-case design

## Application Requirements
- The North Vacation Booking application allows guests to reserve vacation rentals. Reservations must be between 1 and 31 nights and include between 1 and 12 guests.

- The nightly cost is $200, the cleaning fee is $50, and each guest over five costs an additional $25 per night.

## Project Files
- equivalence_partitions.md - Contains the equivalence partition tables.
- test_cases.md - Contains the test cases and expected results.

## Purpose
- This assignment helps me practice identifying valid and invalid inputs, selecting representative values, and designing test cases to check application behavior.
