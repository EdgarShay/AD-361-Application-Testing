# North Vacation Booking – Software Testing Assignment
Written by: Edgar
## Project Overview

For this assignment, I tested the North Vacation Booking application.
I focused on the Creating a Booking feature to see if users could select a rental, enter booking dates,
enter the number of guests, and confirm a reservation.

## Testing Techniques

This project includes four testing techniques:

1. Error Guessing: I thought about common mistakes users might make when creating a booking.
2. Exploratory Testing: I explored the booking form by clicking fields and buttons to see how the application responded.
3. Checklist-Based Testing: I created and performed a checklist to compare expected results with actual results.
4. Acceptance Testing: I wrote acceptance criteria from the user's perspective to see if the booking feature met their needs.

## Testing Results

During testing, I found that the date field displayed a calendar and allowed me to enter a date.
The guest field also accepted different numbers, including 5, 18, and 200. However,
the rental field appeared disabled, and the Confirm Booking button did not respond
when I clicked it without entering information. Because of these problems,
I could not complete a booking or verify that a reservation appeared on the Bookings page.
