# Jest Testing Assignment
Written: by Edgar

## Description

- This project practices unit testing using Jest and TypeScript. The tests check whether selected functions return the expected results.

## Functions Tested

- isEven: Checks whether a number is even or odd.

- palindrome: Checks whether a word reads the same forward and backward.

- countVowels: Counts the vowels in a string.

## Technologies Used

- TypeScript

- Jest

- ts-jest

- Node.js

## How to Run the Tests

- Install the dependencies:

- npm install

- Run the tests:

- npx jest
